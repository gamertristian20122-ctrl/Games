HOLLOW HILL - DEMO (v0.36.0)
A turn-based adventure RPG: pixel people in a lit 3D world.
The demo is chapter one: the lantern town of Wickmere, the Elfwood, the first
fights, one boss, and the first beacon.

HOW TO START (Windows)
  1. Unzip the folder anywhere.
  2. Double-click HollowHill.exe.
  If the picture looks wrong or the game will not start, use
  "HollowHill (safe mode).bat" instead (a simpler renderer).
  Windows may warn about an unknown publisher: choose "More info" > "Run anyway".

CONTROLS (keyboard; a gamepad also works)
  Move            W A S D
  Talk            Q
  Confirm (menus) Enter
  Knight screen   C or Tab   (stats, gear, skills, party)
  Pause / back    Esc
  Fullscreen      F11
  In a fight      arrow keys and Enter; hold Space to fast-forward
  The mouse works on every button.

WHERE TO GO
  Glittering fairy dust on the ground leads to the next story goal
  (Settings > Fairy dust turns it off).

ANDROID
  Install HollowHill_v0.36.0.apk (allow "install unknown apps" when asked).

KNOWN LIMITS OF THIS DEMO
  - The story text is a first draft and will be rewritten.
  - Some places on the world map are locked: they belong to later chapters.
  - Balance has only been checked by a test bot.

All art is purchased or free human-made pixel art; light and effects are code.
No AI-made art or audio. See Credits in the game.
