The release signing key for Cursebait (made 11 Nov 2026, from v0.3.0 on).
Every APK must be signed with THIS key, or phones refuse to install the update over the old app.
The key file is cursebait.keystore; its alias and password are in key.env (tools/build_apk.sh reads it).
This repo must stay PRIVATE. Never copy this folder anywhere public. Never make a new key.
(The v0.2.0 preview was signed with an older key that was lost with its cloud session.)
